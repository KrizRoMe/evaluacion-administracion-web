# ✅ Checklist del estudiante — Evaluación Práctica 01

Usa esta lista para verificar tu avance.

---

## Repositorio — 10 min

- [ ] Creé mi repositorio público.
- [ ] El nombre es `evaluacion-administracion-web-TU-NOMBRE`.
- [ ] Subí los archivos del sitio.
- [ ] Hice commit inicial.
- [ ] Hice push a `main`.

## GitHub Pages — 10 min

- [ ] Activé GitHub Pages (rama `main`, carpeta `/`).
- [ ] Esperé 1–2 minutos.
- [ ] La URL pública carga correctamente.
- [ ] Copié la URL al README.md.

## Auditoría — 15 min

- [ ] Abrí Chrome DevTools (F12).
- [ ] Revisé la pestaña **Elements**.
- [ ] Revisé la pestaña **Network**.
- [ ] Ejecuté **Lighthouse** (Performance).
- [ ] Encontré **3 problemas reales**.
- [ ] Anoté dónde encontré cada problema.

## Issues — 20 min

- [ ] Creé **EXACTAMENTE 3 Issues**.
- [ ] Cada Issue tiene:
  - [ ] Título descriptivo
  - [ ] Problema
  - [ ] Evidencia
  - [ ] Impacto
  - [ ] Solución propuesta
  - [ ] Tipo de mantenimiento
  - [ ] Pilar (VIVO / RÁPIDO / SEGURO)
- [ ] Cada Issue cubre un área diferente (idealmente).

## Corrección — 15 min

- [ ] Corregí **al menos 1 problema**.
- [ ] Hice commit del cambio.
- [ ] Hice push.
- [ ] Verifiqué que GitHub Pages sigue funcionando.
- [ ] Actualicé la Issue correspondiente (cerré o comenté).

## README — 15 min

- [ ] Completé mis datos (Nombre, Código).
- [ ] Pegué la URL del repositorio.
- [ ] Pegué la URL de GitHub Pages.
- [ ] Listé las 3 Issues con sus URLs.
- [ ] Respondí VIVO.
- [ ] Respondí RÁPIDO.
- [ ] Respondí SEGURO (2 acciones).
- [ ] Expliqué backup 3-2-1.
- [ ] Propuse SLI.
- [ ] Propuse SLO.
- [ ] Expliqué SLA.
- [ ] Escribí Runbook de 4–6 pasos.
- [ ] Indiqué qué Issue corregí.

## Verificación final — 5 min

- [ ] El repo es público.
- [ ] Pages funciona.
- [ ] Tengo exactamente 3 Issues.
- [ ] Hay al menos 1 corrección en commits.
- [ ] El README está completo.
- [ ] Las URLs están en el README.
